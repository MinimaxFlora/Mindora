# Internationalization

Mindora 提供三种界面语言：

- 简体中文 `zh-CN`
- 繁體中文 `zh-TW`
- English `en`

## 结构

| 文件 | 作用 |
| --- | --- |
| `src/i18n/messages.ts` | 三语词典、插值、复数、`translate()` |
| `src/i18n/use-i18n.ts` | React hook，读取本地设置中的语言 |
| `src/lib/locale.ts` | 语言常量、检测、HTML `lang`、数字格式化、当前 locale |
| `src/db/seed-content.ts` | 三种语言的首启引导笔记 |

语言偏好保存在本机 `AppSettings.locale`（IndexedDB），**不随账户同步**。主题和编辑器偏好同样属于设备本地设置。

## 使用

```tsx
const { t, locale, setLocale } = useI18n()

t('common.newNote')
t('list.toast.trashed', { count: 3 })
```

- 词典以英文键对象推导 `MessageKey`，缺少任意语言键会在 TypeScript 中报错。
- 字符串中 `{name}` 是插值。
- 带有单复数的文案用 `|` 分隔，例如 `'{count} note|{count} notes'`；提供了 `count` 参数时会按 1 / 非 1 选择。
- 中文两种语言共享部分字符串，但繁体词典显式覆盖了简体字形不同的条目。

## 日期与数字

- `formatRelativeTime`、`formatDateTime`、`formatShortDate` 使用当前 locale。
- 数字使用 `Intl.NumberFormat` 或 `toLocaleString(locale)`。
- 页面切换语言后，这些函数通过 `setActiveLocale()` 同步；React 树会重新渲染。

## 添加新语言

1. 在 `src/lib/locale.ts` 的 `LOCALES` 增加条目。
2. 在 `src/i18n/messages.ts` 增加词典，类型必须满足 `Record<MessageKey, string>`。
3. 在 `src/db/seed-content.ts` 提供首启内容（或复用已有语言并明确说明）。
4. 设置页语言列表与登录页语言选择会自动出现。
5. 运行：

```bash
pnpm typecheck
pnpm test
pnpm test:e2e --project=desktop-chrome
```

## 不应翻译的内容

- 用户已有的笔记正文与标题。
- 用户标签、文件夹名称。
- 代码块、URL、Markdown 语法。
- 品牌名 `Mindora`（但可以调整副标题）。

## 测试

`src/i18n/messages.test.ts` 会检查：

- 三种语言的键集合一致。
- 英文词典不残留中文 UI 文案。
- 插值与单复数。
- 三种语言的首启内容存在。

端到端测试覆盖语言切换与刷新后持久化。

## 引导内容

首次创建本地数据库时，`detectLocale()` 根据浏览器语言选择 `zh-CN`、`zh-TW` 或 `en`。注册后会把这些引导笔记同步到账户。切换语言不会修改已经创建的用户笔记，这是有意设计，避免意外翻译用户内容。
